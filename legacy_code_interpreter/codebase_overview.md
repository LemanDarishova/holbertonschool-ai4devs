# Codebase Overview - Prompt-Recommender (ActasGPT)

## Project Description

Prompt-Recommender is an AI-based prompt recommendation system developed as a third-year university project. It uses Natural Language Processing (NLP), cosine similarity, and Transformer models to generate improved prompts based on user input.

GitHub: https://github.com/uni-ai-archive/Prompt-Recommender
