User Stories
Product: AI-Powered Urban Issue Reporter
The platform helps residents report local infrastructure problems and helps administrators review, prioritize, and track them.
User Stories
1. Submit an issue
   As a resident, I want to submit an urban issue with a description and location so that the problem can be recorded and addressed.
2. Attach a photo
   As a resident, I want to attach a photo to my report so that administrators can better understand the issue.
3. Categorize an issue with AI
   As a resident, I want the system to suggest a category for my report so that it can be directed to the appropriate service.
4. Estimate issue priority
   As an administrator, I want AI to suggest a priority level based on the report so that urgent problems can be reviewed first.
5. Review AI suggestions
   As an administrator, I want to review and edit AI-generated categories and priority levels so that incorrect suggestions do not become final decisions.
6. Track report status
   As a resident, I want to see the current status of my submitted report so that I know whether it is being reviewed or resolved.
7. Manage reports
   As an administrator, I want to view, filter, and update reports so that I can manage incoming issues efficiently.
8. View report details
   As an administrator, I want to see the description, location, photo, AI category, priority, and history of a report so that I can make an informed decision.
9. Receive status updates
   As a resident, I want to be notified when the status of my report changes so that I stay informed about its progress.
10. Prevent duplicate reports
    As an administrator, I want to identify reports that may describe the same issue in a similar location so that duplicate work can be reduced.
MVP Scope
The first version will prioritize stories 1–8. Notifications and duplicate detection (stories 9–10) can be implemented in a later iteration.
