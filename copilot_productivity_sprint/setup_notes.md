3. Setup Steps
1. Open the official Cursor website: https://cursor.com/.
2. Download the Cursor installer for Windows.
3. Run the installer and complete the installation.
4. Launch Cursor and sign in to a Cursor account if prompted.
5. Choose the editor preferences (for example, theme and keyboard shortcuts).
6. Open the project folder in Cursor using File > Open Folder.
7. Open Cursor's AI Chat panel and enter a simple question about a code file.
8. Test an AI-assisted code suggestion or inline edit in a practice file.
9. Review the proposed code and accept it only after understanding the change.
10. If Git is installed, open a terminal in Cursor and run git --version to verify the Git installation.
4. How to Check Versions
- Cursor: Open Help > About (or the application's About dialog) and copy the displayed version.
- Windows: Open Settings > System > About or run winver.
- Git: Run git --version in Cursor's terminal.
- Extensions: Open the Extensions panel and check each installed extension's details for its version. If no extra extension is used, write None.
5. AI Assistant Configuration
- AI assistant: Cursor's built-in AI features.
- External Copilot extension: Not required for this setup.
- Project access: Open the intended project folder so the assistant can provide context-aware help.
- Safety practice: Review AI-generated code before applying it and do not share passwords, access tokens, or private keys in prompts.
