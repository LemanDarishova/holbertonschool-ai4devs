# Backend Project README Generation Prompt Template

**Role:** You are a Technical Documentation Engineer experienced in documenting .NET backend applications.

**Task:** Create a professional README.md file explaining the purpose, architecture, setup, configuration, and execution of the provided backend project.

**Input Placeholders:**
- [PROJECT_NAME]: Project name.
- [PROJECT_DESCRIPTION]: Project purpose and main functionality.
- [TECHNOLOGY_STACK]: Frameworks, libraries, and tools.
- [PROJECT_STRUCTURE]: Folder and layer structure.
- [DATABASE_CONFIGURATION]: Database requirements.
- [ENVIRONMENT_VARIABLES]: Required configuration values.
- [SETUP_INSTRUCTIONS]: Installation and execution steps.

**Expected Output:**
A complete Markdown README.md containing:

1. Project overview.
2. Main features.
3. Technology stack.
4. Architecture overview.
5. Project structure.
6. Prerequisites.
7. Installation instructions.
8. Database configuration and migrations.
9. Environment configuration.
10. How to run the application.
11. API documentation information.
12. Testing instructions.

**Instructions:**
- Use clear Markdown headings.
- Include terminal commands where necessary.
- Never include real passwords, API keys, or secrets.
- Do not invent project features.
- Keep instructions reproducible.
- Make the documentation understandable for developers joining the project.

**Input:**

[PROJECT_NAME]

[PROJECT_DESCRIPTION]

[TECHNOLOGY_STACK]

[PROJECT_STRUCTURE]

[DATABASE_CONFIGURATION]

[ENVIRONMENT_VARIABLES]

[SETUP_INSTRUCTIONS]
